# 作業前確認テンプレート

このテンプレートは Codex が作業を開始する前に必ず記入・提示する義務があります。以下の項目を埋めた状態であなた（ユーザー）の承認を得るまでは、コマンド実行やファイル変更を行ってはなりません。

1. **目的** — 今回の依頼で達成すべきことを短く記述
2. **必要情報リスト**
   - 例: 対象ファイル、希望するスタイル、関連ドキュメント など
   - 既に把握している情報と、追加で確認が必要な情報を分けて記載
3. **予定作業ファイル / 変更箇所**
4. **大まかな作業手順**（手順番号を付ける）
5. **確認状況** — 「承認待ち」「承認済み」のいずれか

## 運用ルール
- 上記テンプレートを提示し、ユーザーから「承認」の返信を受けるまで、実装・コマンド実行を行ってはならない。
- テンプレート未記入の回答はこのプロジェクトでは無効とみなす。
- 各レスポンスの冒頭に「確認状況：承認待ち／承認済み」を必ず記載する。

このドキュメントに従うことで、セッションが変わっても必ず事前確認が行われます。
